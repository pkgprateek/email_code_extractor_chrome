# Privacy Policy for CodeSnap for Gmail

**Last Updated**: November 24, 2025

## Overview

CodeSnap for Gmail is a Chrome extension designed to help users quickly identify and copy verification codes from their Gmail inbox. This privacy policy explains how the extension handles user data.

## Data Collection

Email Code Extractor does **NOT** collect, store, or transmit any user data. The extension operates entirely within your browser.

## Data Processing

The extension:
- Reads the visible text content from Gmail's list view (subject lines and snippets)
- Processes this text locally in your browser to identify potential verification codes
- Does not access the full content of your emails
- Does not store any email content or extracted codes
- Does not send any data to external servers

## Permissions

The extension requests the following permission:

- **activeTab**: Allows the extension to interact with the Gmail page you are currently viewing. This is necessary to read email subjects and snippets and inject the code badges.

## Third-Party Services

CodeSnap for Gmail does not use any third-party services, analytics, or tracking tools.

## Data Security

All code execution happens locally in your browser. No network requests are made by this extension.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be posted in this document with an updated "Last Updated" date.
