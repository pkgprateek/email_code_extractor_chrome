```
## Changes

### Rebranding
- Rename extension from "Email Code Extractor" to "CodeSnap for Gmail"

- Update GitHub repository references
- Change license from GPL v3 to MIT for future flexibility

### Improvements
- Exclude ordinal numbers (21st, 2nd, 3rd)
- Exclude duration patterns (1-month, 3-days)
- Exclude standalone words like "Time"
- Increase detection threshold to reduce false positives
- Boost purely numeric codes to prioritize real OTPs
- Add comprehensive test coverage for new exclusions

### Release
- Build production package v2.0.0
- Prepare for Chrome Web Store submission
- Add support contact information in store listing

This is a complete rewrite with modern tech stack (React, TypeScript, Vite)
and significantly improved accuracy in code detection.
```
